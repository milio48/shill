🏴‍☠️ Shill

"The Stowaway" — portable standardized userspace

A single POSIX shell script that bootstraps a portable userspace on any Linux server — even the most restricted shared hosting. No root, no sudo, no package manager required.

Install Packages GitHub

⚡ Instant Setup

curl -fsSL https://raw.githubusercontent.com/milio48/shill/main/shill.sh -o shill.sh && chmod +x shill.sh && ./shill.sh setup

No curl? Use wget:

wget -qO shill.sh https://raw.githubusercontent.com/milio48/shill/main/shill.sh && chmod +x shill.sh && ./shill.sh setup

✨ Why Shill

No root

Runs entirely in your home directory. Nothing system-wide.

Portable

Move the core anywhere; config, caches and prefixes travel with it.

Batteries included

300+ commands via a BusyBox farm, plus a package registry.

Always latest, pinnable

Packages track upstream releases; pin with pkg@version.

Long tail

Install anything on demand with pkgx / webi.

Rootfs when needed

Full distro shells via proot-alpine / proot-ubuntu.

🎮 Basic Usage

./shill.sh enter                 # interactive shell
./shill.sh install <pkg>          # install a package
./shill.sh install node@20.11.0  # pin a version
./shill.sh remove <pkg>           # remove cleanly
./shill.sh ls                    # list packages (A–Z, offline-friendly)
./shill.sh destroy               # wipe the environment
